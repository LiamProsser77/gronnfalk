# Code of Conduct

## Our Commitment

We want GronnFalk to be a welcoming, respectful, and friendly open-source project for everyone.

## Expected Behavior

- Be respectful and kind to others.
- Give constructive feedback.
- Respect different opinions and experiences.
- Help keep discussions focused and productive.
- Give credit to other contributors for their work.

## Unacceptable Behavior

The following behavior is not welcome:

- Harassment, bullying, or personal attacks.
- Hate speech or discrimination.
- Threats or intimidation.
- Sharing private information about others.
- Trolling or deliberately disrupting the project.
- Any other behavior that makes the community unsafe or unwelcoming.

## Reporting Problems

If you experience or see unacceptable behavior, please report it through the project's GitHub Issues or contact the project maintainer privately.

Reports will be reviewed and handled as fairly as possible.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or take other appropriate action when this Code of Conduct is violated.

## Scope

This Code of Conduct applies to the GronnFalk repository, its discussions, issues, pull requests, and other official project spaces.

Thank you for helping make GronnFalk a friendly and open project.
