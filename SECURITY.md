# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in GronnFalk, please report it privately rather than publicly posting it in a GitHub Issue.

This helps protect GronnFalk users while the issue is being investigated and fixed.

## How to Report

Please contact the GronnFalk maintainer privately through GitHub with:

- A description of the vulnerability.
- Steps to reproduce it.
- Any relevant screenshots, code, or other details.
- The potential impact of the issue.

## Please Do Not

- Publicly disclose an unfixed security vulnerability.
- Attempt to access other people's private information.
- Intentionally damage or disrupt GronnFalk services.
- Use a vulnerability to harm other users.

## Security Updates

Security issues will be investigated and fixed when possible. Important security fixes may be announced through the GronnFalk repository.

Thank you for helping keep GronnFalk secure.
