AI Policy
=========

GronnFalk is committed to providing a simple, private, and independent
search experience without artificial intelligence.

No AI
-----

GronnFalk does not use artificial intelligence as part of its search engine.

GronnFalk will not use AI to:

* Generate search results
* Generate answers or summaries
* Profile users
* Analyze search queries
* Rank users or their behavior
* Train AI models using user data
* Generate advertisements
* Make decisions about users

Permanent No-AI Commitment
--------------------------

GronnFalk is intentionally designed without artificial intelligence.

The project will not introduce AI-powered search, generative AI features,
AI assistants, AI summaries, or similar AI functionality into the core
GronnFalk search experience.

This is a deliberate design decision.

Third-Party AI Services
-----------------------

GronnFalk does not intentionally send user search queries or search results
to third-party AI services.

The project does not depend on AI APIs or AI providers to provide its core
search functionality.

Pull Request AI Disclosure
--------------------------

All contributors submitting a pull request to GronnFalk must disclose
whether artificial intelligence was used while creating the contribution.

This disclosure must be included in the pull request description.

If no AI was used, contributors should state:

::

    AI used: No

If AI was used, contributors must state:

::

    AI used: Yes
    AI tool: <name of AI tool>
    Usage: <brief description of how the AI was used>

Examples of AI tools include, but are not limited to:

* ChatGPT
* Claude
* GitHub Copilot
* Gemini
* Microsoft Copilot
* Cursor
* Other AI coding or generative AI tools

Contributors should provide the actual name of the tool they used.

For example:

::

    AI used: Yes
    AI tool: ChatGPT
    Usage: Helped explain an error and suggested a possible fix.

Or:

::

    AI used: Yes
    AI tool: Claude
    Usage: Assisted with reviewing and improving the code.

AI disclosure is required even when AI was only used for a small part of
the contribution.

Why Disclosure Is Required
--------------------------

AI disclosure helps maintain transparency within the GronnFalk community.

It allows maintainers and contributors to understand how a contribution was
created and helps maintainers properly review AI-assisted contributions.

Using AI does not automatically mean that a pull request will be rejected.
However, contributors must be honest about AI usage.

False or Missing Disclosure
---------------------------

Contributors must not intentionally claim that AI was not used when AI was
used to create or substantially assist with a contribution.

Pull requests may be requested to provide an AI disclosure before they can
be reviewed or merged.

Transparency
------------

GronnFalk values transparency in both its code and its community.

The project will clearly document its use of technology and will not
secretly introduce AI processing into the search experience.

Open Source
-----------

GronnFalk is open source, allowing the community to inspect how the project
works and how search data is processed.

----

**No AI. No profiling. Just search.**
