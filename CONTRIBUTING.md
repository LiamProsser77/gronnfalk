# Contributing to GronnFalk

Thank you for your interest in contributing to GronnFalk!

GronnFalk is an open-source, privacy-focused metasearch engine. Contributions, ideas, bug reports, and improvements are welcome.

## How to Contribute

### Report a Bug

If you find a bug:

1. Check the existing GitHub Issues to see if it has already been reported.
2. Open a new issue if it has not been reported.
3. Explain what happened and how to reproduce the problem.

### Suggest a Feature

Have an idea for GronnFalk?

Open a GitHub Issue and describe:

- What the feature would do.
- Why it would be useful.
- How you think it could work.

### Submit Code

To contribute code:

1. Fork the GronnFalk repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit and push your changes.
6. Open a Pull Request.

Please keep Pull Requests focused on one feature, improvement, or fix when possible.

## Code Style

Try to keep code:

- Simple and readable.
- Consistent with the existing project.
- Well organized.
- Free of unnecessary changes.

## Pull Requests

Pull Requests may be reviewed before being merged.

Please explain what your Pull Request changes and why the change is useful.

Not every Pull Request is guaranteed to be accepted. Changes should fit the goals and direction of GronnFalk.

## Be Respectful

Please follow the [GronnFalk Code of Conduct](CODE_OF_CONDUCT.md).

Be respectful, helpful, and constructive when working with other contributors.

## AI Policy

**GronnFalk does not use AI in its search engine.**

All pull requests must disclose whether AI was used and, if so, which AI tool was used.

**[Read our AI Policy](AI_POLICY.rst)**

## Thank You

Every contribution helps GronnFalk improve.

Whether you report a bug, suggest an idea, improve the documentation, or contribute code, **thank you for helping make GronnFalk better!**
